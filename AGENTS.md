# Repository guide for coding agents

This is a Yarn 1/Lerna 8 monorepo for the Progressive UI design system. Use Node 22.12 or newer and Yarn 1.22.22. The compatibility contract is the React package's public exports, component behavior, CSS classes, generated CSS, and design-token names.

## Canonical commands

Run commands from the repository root:

```sh
yarn install --frozen-lockfile
yarn lint
yarn typecheck
yarn test
yarn build:packages
yarn build:storybook
yarn build:website
yarn verify:packages
yarn verify:public-exports
yarn verify:bundle-size
```

`yarn validate` runs the full sequence used before versioning or publishing. Never run a publish or version command merely to test it.

## Package map

- `packages/react`: public React component library. `src/index.ts` is the runtime public surface.
- `packages/styles`: public Sass sources and generated `styles.css`.
- `packages/themes-core`: public token artifacts and the Style Dictionary v3-compatible theme builder.
- `packages/icons`: private source SVG workspace.
- `packages/icons-core`: public icon-generation tooling.
- `packages/icons-react`: generated public React icon package.
- `packages/website`: private Next.js documentation site.

## Generated boundaries

- Default token source: `packages/themes-core/tokens`; local output: `dist`.
- `packages/themes-core/distDark` is a tracked legacy artifact. Do not regenerate
  it until the dark source has a golden name/value compatibility fixture.
- Icon source: `packages/icons/src/svg`; output: `packages/icons-react/es` and `umd`.
- React library output: `packages/react/dist`.
- Website component metadata: `packages/website/types`, generated by `yarn generate:website-assets`.
- Storybook output: `packages/react/docs`.

Do not hand-edit generated output. Run the owning generator and confirm `git status --short` has no unexpected changes afterward.

## Compatibility and legacy rules

- Compare runtime exports with `yarn verify:public-exports` after touching `src/index.ts` or packaging.
- Keep ESM, CommonJS, UMD, and declaration consumers working.
- Do not rename CSS classes or token names during tooling work.
- `packages/react/othersrc`, `*.legacy.*`, and `*-old*` are quarantined, not deletion candidates. Read `packages/react/LEGACY.md` first.
- JavaScript `*-test.js` files are the isolated Enzyme suite. Migrate a suite to Testing Library before removing it or Enzyme.
- Redux Form and React Table v7 are compatibility dependencies for legacy/internal examples; do not upgrade or remove them without an explicit migration.
- `yarn workspace @progressiveui/themes-core build:tokens` performs authenticated remote synchronization. Routine local validation uses `yarn generate:tokens` and must not require credentials.

## Change discipline

- Preserve unrelated working-tree edits.
- Prefer small Conventional Commits.
- Record an existing failure separately from a regression.
- Validation must complete before any version, tag, or publish operation.
- Never print `.npmrc`, environment values, registry tokens, or Azure secure-file contents.
